## Booking links

Booking buttons are intentionally disabled until real reservation URLs are added.

Open `app.js` and set the `bookingUrl` value for each collection:

```js
{
  name: "The Winter Cottage",
  // ...
  bookingUrl: "https://your-booking-link.com"
}
```

Once a URL is present, the page automatically enables the button for that collection.

## Design direction

The site is intentionally typography-led and clean. It does not use placeholder photography, faux postage stamps, postcard frames, or decorative fake assets. Approved campaign photography can be added later without changing the content structure.
